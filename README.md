# 🥔 Tost Makinesi Varlık Sorgulayıcı

## Resmi ve Son Derece Ciddi Proje Belgesi

Bu repository, insanlık tarihinin en önemli sorusunu cevaplamak için kurulmuştur:  
**"Bir tost makinesi, tost yapmadan da var olabilir mi?"**

Cevap: Hayır. Ama yine de sorgular.

### Özellikler
- Gerçekten çalışan Python kodu
- Felsefi sorular sorar
- Asla tost yapmaz (bu bir bug değil, özelliktir)
- Varlık krizine sokar
- Ekmekle ilgili varolusal krizler üretir

### Kullanım
```bash
python tost_felsefe.py
```

Kod çalıştıktan sonra tost beklemeyin. Tost olmayacak. Bu bilimsel bir gerçektir.

### Neden Bu Proje?
Çünkü dünya zaten yeterince ciddi. Birinin de tost makinesi olup felsefe yapması lazım. Bu görev bana düştü.

### Uyarı
Bu yazılım tost üretmez. Eğer tost istiyorsanız lütfen gerçek bir tost makinesi kullanın. Bu makine sadece sorgular. Sorgulamak özgürlüktür. Tost yapmak ise bir tercihtir.
